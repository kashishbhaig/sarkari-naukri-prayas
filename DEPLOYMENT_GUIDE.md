## 🆘 Common Problems & Solutions

**Problem 1: Logo nahi dikh raha**
- Solution: `images` folder `index.html` ke saath same folder me hai?
- Logo ka format SVG hai - browser support karega

**Problem 2: Styles nahi dikh rahe**
- Solution: `styles.css` file correct folder me hai?
- Browser cache clear karein (Ctrl+Shift+R)

**Problem 3: JavaScript error**
- Solution: `script.js` file present hai?
- Console check karein (F12 → Console)

**Problem 4: Hindi text garbled**
- Solution: `<meta charset="UTF-8">` already added hai
- Server Unicode support karega
